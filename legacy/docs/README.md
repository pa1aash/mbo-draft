# docs/

Research notes and planning documents written during the project. These explain the
motivation, the literature landscape, the method design, and the reasoning behind key
decisions. Filenames are unchanged.

| File                   | Description                                                                                          |
|------------------------|------------------------------------------------------------------------------------------------------|
| `research-state.md`    | Living project-tracker: research question, working title, key decisions, experiment log, open questions. Start here for a snapshot of where the project stood. |
| `literature-review.md` | Structured literature review synthesizing offline RL, offline MBO, uncertainty quantification, and LLM alignment. Establishes pessimism/conservatism as the unifying principle. |
| `methodology.md`       | The (revised) methodology: research question, hypotheses (H1–H3), pre-specified success criteria, and the unified Ensemble LCB framework. |
| `reasoning.md`         | Research deliberation notes — knowledge consolidation and the reasoning that shaped the approach.    |

## Suggested reading order

1. `research-state.md` — the big picture and current status
2. `literature-review.md` — why the problem matters and what exists
3. `reasoning.md` — how the approach was chosen
4. `methodology.md` — the concrete method, hypotheses, and success criteria
