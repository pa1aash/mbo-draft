## N6 Verdict: The Crossed Surrogate x Optimizer Factorial

### A. The verdict, and what a kill would require

**CONFIRMED NONE-FOUND**, with one paywalled lead unresolved and named in section F below rather than in the terminal section.

A kill requires four conjuncts simultaneously, in an offline or fixed-dataset setting:

- **(a)** surrogate **model class** varied across at least two genuinely distinct classes;
- **(b)** optimizer or search routine varied across at least two routines;
- **(c)** the two axes genuinely **crossed**, every surrogate run with every optimizer;
- **(d)** a **two-way variance decomposition** of the outcome — an attribution of variance to each axis and their interaction — rather than a leaderboard.

Conjunct (a) matters because a training-objective swap inside one architecture is a different kind of factor; (b) because a bundled end-to-end method is not a clean optimizer level; (c) because a one-factor-at-a-time (OFAT) design, which holds all inputs fixed but one, cannot estimate interactions; (d) because descriptive per-cell reporting is not an attribution. No paper found satisfies all four.

### D. Three grounds, one falsified on contact

The paper's residual is defended against RaM on three grounds. One is false as stated, and the paper should concede it before a reviewer does.

| Ground | Status |
|---|---|
| **(1) Loss type ≠ model class** | **SURVIVES**, now with domain support. The canonical uncertainty-quantification survey catalogues method family as the top-level taxonomy and loss function as a separate cross-cutting axis in its own tables [11]. The paper's nearest comparator treats model class as constitutively bound to its fitting procedure [12] — no GP posterior without marginal-likelihood fitting, no ensemble without per-member training — whereas RaM swaps MSE for ListNet *inside one unchanged MLP* [2]. Statable criterion: a change is model-class if it cannot be instantiated without changing the estimator family, and training-objective if it can be applied at fixed family. The concession that makes this honest rather than convenient: **no statistical theory adjudicates what counts as one factor.** NIST/SEMATECH assigns factor identification to domain judgment outright — *"Guidelines to assist the engineering judgment process of selecting process variables for a DOE... Include all important factors (based on engineering judgment)"* [93] — so ground (1) was never going to find an abstract arbiter; what it can find is domain precedent, which is what [11] and [12] supply. **Evidentiary base, stated where the verdict is given:** one uncertainty-quantification taxonomy plus the comparator's convention, with the criterion itself proposed rather than sourced. No source was found treating model class and training objective as one factor, but the AutoML and kernel-selection region was searched for crossed designs rather than for that taxonomic question, so the base is narrow |
| **(2) Bundled methods ≠ a clean optimizer factor** | **FALSIFIED AS STATED.** RaM's own Appendix E.5 describes four of its nine methods — BO-qEI, CMA-ES (covariance matrix adaptation evolution strategy), REINFORCE and gradient ascent — as "baselines that optimize a trained model." **A clean 4 × 2 crossed optimizer × loss sub-grid exists inside Table 3, in offline MBO, published before this submission** [2]. The ground survives only for the other five: CbAS and MINs are genuinely aliased in the strict design-of-experiments sense, and NIST's definition is a test a reader can apply rather than a label — *"Confounding means we have lost the ability to estimate some effects and/or interactions"* [13]: for these two, model family and search paradigm co-occur on every run and cannot be estimated apart — while Tri-Mentoring, PGS and Match-OPT layer method-specific machinery on top |
| **(3) Descriptive reporting ≠ a decomposition** | **SURVIVES**, but must be stated as a claim about what RaM *reports*, since this audit itself derived the decomposition from RaM's published table |

**The uncomfortable finding.** Defending N6 against RaM required computing a two-way ANOVA from RaM's own published Table 3, which reports mean and standard deviation per cell over a uniform eight seeds — so both moments and the sample size are available for all ninety cells. That computation takes about fifteen lines of code and yields **a loss axis at η² ≈ 0.027 against a method axis at η² ≈ 0.577** [2]. This *strengthens* "no prior work **reports** a crossed surrogate × optimizer decomposition," which is still true, and *destroys* "no prior work **could have**," which this audit disproved in under a day. **N6 must therefore be stated as a claim about what the literature reports, never about what the design space permits.** The contribution is running the decomposition as the primary analysis on a purpose-built grid, not the arithmetic itself.

It also yields an observation worth keeping — and one inference that must be withdrawn. The complete decomposition of RaM's Table 3 is η²_method = 0.577 [per-task range 0.134–0.958], η²_loss = 0.027 [0.0004–0.076], η²_method×loss = 0.055 and η²_within = 0.341, so the split is far less stable across tasks than the two headline numbers suggest [2]. That two crossed grids in the same subfield, decomposed the same way, attribute variance differently is a reportable observation.

**It is not independent evidence for ground (1), and the earlier framing of it as such is FALSIFIED.** RaM's 0.577 sits on its *bundled method* axis — the axis this report's own conjunct (b) insists is not a clean factor, mixing model family, search paradigm and bespoke machinery in one level — so it is not commensurable with this paper's optimizer axis, and "swapping model class moves the dominant share" does not follow from it. What survives is local to RaM's own grid. One structural point does cut independently for the residual: RaM's Appendix E.5 records that COMs, RoMA, IOM, BDI and ICT were excluded from the loss swap because their losses use prediction values or per-sample weights incompatible with a drop-in MSE-to-ListNet replacement — **the crossing is an opportunistic subset of methods, not a designed factorial**, which is precisely the difference the paper claims. Both η² figures were computed once, by one implementation, with no independent reimplementation.

**The grounds are nowhere on the page.** The introduction files `tan2025ltr` under "surrogate-class comparisons hold the optimizer constant," beside `li2024bnnsurrogates` [12]. That is accurate about RaM's *main* experiment — the five-surrogate Spearman comparison genuinely holds gradient ascent fixed — so the sentence is **incomplete rather than false**, and the distinction matters. But it is incomplete in exactly the direction that makes RaM look safely outside the residual before a reader checks Table 3.

### A. `demsar2006statistical` — a threshold that does not exist, attached to inverted reasoning

**The claim** (`main.tex:220`, echoed in the contributions list): *"we are below the threshold for the test we ran: this omnibus is recommended for more than ten datasets."*

**The source contains nothing of the kind.** The full thirty-page JMLR paper was extracted (103,393 characters) and grepped directly [41]: `more than ten` = **0**, `at least ten` = **0**, `ten or more` = **0**. The only two occurrences of "ten data sets" describe Demšar's own power-simulation sampling procedure — "samples of ten data sets were randomly selected," "1000 random selections of ten data sets."

This is not an over-read of something stated loosely. **It is a specific numeric recommendation attributed to a real source that does not make it**, in a paper whose entire rhetorical position is that unstated protocol details are the field's central methodological failure. And it inverts his reasoning, which matters more. Demšar recommends "a set of simple, yet safe and robust non-parametric tests... the Friedman test with the corresponding post-hoc tests for comparison of more classifiers over multiple data sets," with no dataset-count floor anywhere, and his stated design context is explicitly the small-*n* regime: "the number of data sets is usually much less than 30." **He recommends the non-parametric route precisely because *n* is small.** His own Figure 5 independently shows Friedman as more powerful and more replicable than ANOVA at small samples.

**Fix — and it is a net gain.** Delete the clause and the citation. The conclusion is unaffected and better supported without them: the power limitation is independently established by the same sentence's paired-test calculation (|d_z| ≥ 1.27 for 80% power at α = 0.05, *n* = 7) and by Agarwal's never-claim-equivalence point, which is verified verbatim and correctly used [42]. **The fix removes a false warrant and an unnecessary self-deprecation at once — the paper was conceding a methodological weakness it does not have.**

### B. `fan2024minucb` — three uses, three failures, one of them inverting a theorem

Fan, Wang, Ng & Hu, NeurIPS 2024; full text extracted and grepped across 1,550 lines [22].

**B1. "UCB-as-local-search" is not established prior work.** The paper writes *"as is the reading of a UCB-style acquisition as local search"* — presenting it as settled. Fan et al.: *"we **propose** our first algorithm... MinUCB, which **replaces** gradient descent step with a step that minimizes the UCB in GIBO,"* and *"This discovery... **opens up possibilities for new designs**."* A 2024 method proposal, not an established reading. The underlying two-stage premise traces to GIBO, which Fan et al. explicitly modify — and **GIBO's exploitation step is plain gradient descent with no confidence bound anywhere** [86].

**B2. The LCB-paralysis citation inverts the source's central result — the most serious item in this deliverable.** The paper: *"The surviving mechanism is LCB paralysis: the GP's lower confidence bound is locally maximal at the data, so the optimizer never leaves... This is the offline instance of a known reading of UCB-style acquisitions as local search, applied rather than discovered."*

Full-text grep of Fan et al. returns **zero hits** for `offline`, `LCB`, `lower confidence bound`, `stuck`, `frozen`, `freeze` and `paralysis` [22]. They define UCB(x) = μ(x) + βσ(x) — the upper confidence bound, an optimism-weighted posterior score — and **minimize** it because their objective is minimization; they never treat a maximization setting and never mirror the transform. Decisively, **their Theorem 1 proves MinUCB converges to a genuine local optimum**, at rate O(σ d^{3/2} T^{−1/2} log^{1/2} δ^{−1}), and their §6 states the preconditions in their own words: *"According to Theorem 1, we need to iteratively increase the UCB coefficient β_t and batch size b^{(1)}_t, b^{(2)}_t to guarantee the convergence of MinUCB."* Both preconditions — an *increasing* β schedule and a *growing per-iteration batch*, which is continual active resampling — are structurally impossible on a static offline dataset with no further oracle queries. Two independent impossibilities is a stronger conviction than one. **The paper cites this convergence result as authority for an "optimizer never leaves" failure mode.** That is not a stretched source; it is a source pointing the other way.

**B3. The distance-aware co-citation is unsupported.** Fan has zero hits for `distance-aware` and uses vanilla GP posterior variance throughout.

**Fix (mandatory).** Drop `fan2024minucb` from the LCB-paralysis sentence and the distance-aware co-citation; restate it as a recent method proposal if kept at all. **This costs the paper nothing and removes a reviewer's cleanest kill**, because the paper's own evidence is stronger than the borrowed authority: bit-identical constants across sixteen seeds, in two GP classes, on a continuous task with no argmax decode.

**A correction this audit owes itself.** An earlier pass concluded "nobody owns the trapped-at-the-data failure mode, so claim it outright." That was reached by *excluding* three candidates — TuRBO, whose diagnosis is the opposite pathology of over-exploration and whose locality is deliberately imposed via trust regions [23]; Fan, who proves convergence; GIBO, which uses no confidence bound [86] — without sweeping the vocabulary. Sweeping the family tightens the point rather than loosening it: Wu et al.'s independent convergence-rate analysis of GIBO, the lemma Fan's own Theorem 1 builds on, contains no `stuck`, `trust region`, `offline` or `distance-aware` vocabulary anywhere, so local Bayesian optimization as a literature proves progress rather than paralysis [99].

**Swept, the "no prior art" phrasing is WITHDRAWN.** Yarotsky (2013), "Examples of inconsistency in optimization by expected improvement," is the closest prior formalization in existence: Theorem 3 proves that expected-improvement-driven Bayesian optimization started at the true optimum has a trajectory converging back to that point and "not dense" [24]. It differs on three real axes — expected improvement rather than a confidence bound, online rather than offline, an adversarial worst-case start rather than a seed-robust empirical observation — so it is **a citation obligation, not a kill**. Two adjacent candidates are genuinely different and merit a sentence: Ament et al. diagnose a *numerical* vanishing-gradient pathology specific to expected improvement [87], and Kim & Choi bound the regret gap between local and global acquisition optimizers, touching GP-UCB but concerning within-round inner-optimization fidelity rather than the outer-loop claim [25].

### C. `liu2020sngp` — cited to bound a claim its own Figure 1 contradicts

**The claim:** *"σ is a distance signal, not an error signal... this is the corrected measurement, **bounded by prior work on distance-aware uncertainty** \citep{liu2020sngp,vanamersfoort2020duq}."*

**SNGP argues the opposite, about the exact model class at issue.** Verbatim: *"deep ensembles... are based on dense output layers that are **not distance aware**. As a result, both methods quantify their predictive uncertainty based on the distance from the decision boundaries, **assigning low uncertainty to OOD examples even if they are far from the data**"* [26]. Its Definition 1 formalizes input-distance-awareness — the property that a model's uncertainty is a monotone function of distance to the training data — as something standard deep models **lack**, and that lack is its entire motivation for a GP output layer with spectral normalization. DUQ corroborates: *"DUQ is certain only on the data distribution, and uncertain away from it: the ideal result. Deep Ensembles is uncertain only along the decision boundary, and certain elsewhere"* [27]. A second, independent scope problem: **all SNGP validation is classification** — a 2D toy, Wide-ResNet on CIFAR, ImageNet, BERT — with zero regression experiments, against a paper that is regression throughout.

**Fix.** The claim cannot be "bounded by" a source that predicts the opposite. Best option: **reframe as a contrast** — "unlike the ensembles SNGP and DUQ characterize as distance-unaware, ours shows a modest positive distance correlation (ρ ≈ 0.26)." That is weaker as an appeal to authority and considerably more interesting as a result. **A finding that runs against SNGP is more publishable than one leaning on it, provided it is labelled as such.** State the classification/regression gap either way.

### D. The σ dichotomy is a false opposition, and the resolution is scoping

**A direct counterexample exists, in regression, peer-reviewed.** Carrete et al., neural-network force fields: *"the Spearman correlation coefficient between uncertainty and error over the validation data set is **0.90 for the committee and 0.91 for the bootstrap-aggregation ensemble**"* [28] — roughly **thirteen times** the paper's ρ ≈ 0.07. A second, independent domain reports deep-ensemble uncertainty correlating with per-pixel error at Pearson 0.715 in seismic-facies segmentation [32].

**But the resolution is scoped, not a rout.** Carrete's 0.90 is measured on validation data from the *same* distribution as training; on their genuinely out-of-distribution test the per-atom correlation degrades while remaining informative in aggregate [28]. The paper measures where an optimizer has pushed designs off-support. SNGP and DUQ measure classification on a 2D toy geometry. **All three can be right — which means the dichotomy itself is the defect.** The literature does not treat distance-awareness and error-tracking as mutually exclusive; SNGP explicitly ties distance-awareness to both calibration and OOD detection [26], and the large-scale shift benchmark finds deep ensembles the *best-performing* uncertainty method under dataset shift [30].

**A narrower caveat survives, stated precisely because an earlier framing over-reached.** Lakshminarayanan et al. contrast their NLL-trained heteroscedastic ensemble against *"a commonly used heuristic... to train an ensemble of NNs to minimize MSE and use the empirical variance of the networks' predictions as an approximate measure of uncertainty,"* showing the naive variant *"consistently underestimates the true predictive uncertainty"* — an 80% nominal interval covering roughly 20% of test observations [29]. **The paper's ensemble is exactly that construction.** But the counterweights must travel with it: Ghasemipour et al. treat standard initialization-seed-diversified ensembles — the audited construction — as the *reliable reference*, and what fails in their study is weight-shared "efficient" approximations the paper does not use [49] — carried here under the scoping discipline (i.I) applies to that source, since its "reliable reference" status transfers to a regression surrogate only by argument; D'Angelo & Fortuin note standard ensembles "do not offer any guarantees for diversity," yet their own table shows a standard ensemble winning OOD detection in one setup [31]; Fort et al. measure function-space diversity rather than input-distance awareness, so they neither support nor undercut the ρ figures [90]; and on Lakshminarayanan's own 1D regression toy, the NLL-trained ensemble's predictive standard deviation *does* grow with distance from data. **Net: "this specific σ construction has a known calibration caveat," never "MSE ensembles are broken."** One thread inside that net stays genuinely unreconciled and should be labelled rather than arbitrated: one source treats the MSE-plus-empirical-variance construction as the reliable reference [49] while another flags it as the weaker of two options [29], and nobody has reconciled them directly.

**Fix, two parts.** Scope the framing to this grid — "on our tasks, σ tracks distance more than error" — and **drop the dichotomy**, which is a framing fix independent of the numbers. Add one paragraph acknowledging ensemble construction as an unexamined alternative explanation for ρ = 0.07.

### E. `li2024bnnsurrogates` — the "extends below" claim is false as written

**The claim (Confound 3):** *"Our sweep runs over K ∈ {2,3,5,10} and therefore **extends below** the K ∈ {5,10} range over which ensemble surrogates were found robust, **sharing its two upper points and adding K=2,3**."*

**Figure A.7 tests K = {2, 5, 10}.** Verified first-hand: arXiv:2305.20028v2 was fetched directly (39 pages, 111,042 characters) and the Figure A.7 legend tokens on page 28 read `['2 Models', '5 Models', '10 Models']`; a second, independent route reached the same result by rendering that page as an image [12]. Their verbatim finding from the same caption: *"the different ensembles perform similarly across many experiments, showing the robustness of our results to this hyperparameter."* A second K=2 appearance is in Figure A.5, and the main text adds that these hyperparameters "generally have minimal effects on the performance."

**So the range is {2,5,10}, the prior work already went to K=2 and found robustness there, and the claimed residual collapses from "adding K=2,3" to "adding K=3."** This is worse than a wording slip. The K-sensitivity framing exists to establish that the headline sits at the maximum of a sensitive curve, and the closest prior work reports the opposite conclusion over an overlapping range including the very endpoint the paper claims to have contributed. A reviewer from that group — a live possibility in a community this small — reads the sentence as the paper claiming credit for their experiment.

**Fix, and it must be a real fix.** (1) Correct the range wherever `{5,10}` appears. (2) State the residual, which is real and appears nowhere in the paper: **they measure ensemble-BO *performance* robustness; the paper measures whether the *variance attributed to the surrogate axis* is robust.** Those are different quantities and both can be true; made explicit, the claim survives in a narrower and more interesting form. (3) Keep the K-sensitivity result — it is real. Delete only the priority claim. The year trap is clean and the paper has it right: the arXiv comments field reads "ICLR 2024" against a v1 date of 31 May 2023 [12].

**A second, independent tension with the same source — and this one converts into a result.** Li, Rudner & Wilson state in their abstract that *"the ranking of methods is highly problem dependent, suggesting the need for tailored inductive biases,"* and their body names dimensionality as a driver: *"GPs do not scale well to high-dimensional input spaces without careful human intervention... BNN surrogates can learn the non-stationarity of the function"* [12]. That predicts, qualitatively, that the GP advantage should **decay with dimension**. This paper's own seven-task data shows no dimension relationship in either direction under any optimizer — Spearman 0.107 under gradient, −0.109 under perturbation, 0.071 under CMA, all indistinguishable from zero. **Fix: state it.** A measured, falsifiable refinement of a named prior expectation is the same shape of contribution as the Fannjiang reframing at (i.J), and it strengthens rather than weakens the paper's other uses of `li2024bnnsurrogates`.

### F. `abe2022ensembles` — cited for a direction the source never measures

**The claim (Confound 3):** *"the decline with K runs against **the direction reported for ensemble quality**."*

### G. `rahaman2019spectralbias` — motivates the wrong ablation, and the architecture compounds it

**The claim (Elimination 2):** *"wide networks approach GP behaviour \citep{jacot2018ntk,lee2018dnngp,lee2019widenets} and **finite networks show spectral bias** \citep{rahaman2019spectralbias}... so we ran the ablation that does. At fixed K=5, sweeping per-member **width** over a 10.7× range leaves the gap unchanged."*

**Three of the four citations verify clean, and the audit should say so.** Jacot supplies the neural-tangent-kernel (NTK) mechanism and the training-time Gaussian result [46]; Lee 2018 the at-initialization neural-network-Gaussian-process (NNGP) correspondence [47]; Lee 2019 the proof that wide networks evolve as linear models under gradient descent [48]. Together they cover "wide networks approach GP behaviour," at initialization and during training. Two elided nuances. Lee 2019's own text notes the gradient-descent-limit GP is "noticeably different" from the NNGP Bayesian posterior. And Lee 2018 explicitly declines the inference the audited paper draws: *"Whether gradient-based stochastic optimization implements an approximate Bayesian computation is an interesting question... Further investigation is needed to determine if SGD does approximately implement Bayesian inference"* [47]. Both are precision gaps rather than falsifications. Jacot's §6.1 finite-width ablation is the one place in the cluster where a finite-width effect is actually measured — the NTK "shows less variance and is smoother" at n=10000 than at n=500 — which is directly on point for a 96-to-1024 sweep [46].

**Rahaman is a different story.** The theorem holds *"for arbitrary width and depth"* — not a width-limit statement. The defining experiment varies training *iterations*, not width. And their own controlled ablation finds: *"increasing the depth (for fixed width) significantly improves the network's ability to fit higher frequencies... increasing the width (for fixed depth) also helps, but the effect is **considerably weaker**"* — despite width scaling exponentially (16→32→64→128) against depth's linear increase (3→4→5→6) [45]. **The paper cites spectral bias to motivate a width ablation when the source says width is the weak lever**, and the sentence structure ("wide... **and** finite...") invites a width-monotonic reading the source argues against.

**The architecture compounds it.** `main.tex:88` fixes the ensemble at a two-hidden-layer MLP across the entire width sweep. **The paper varies the axis Rahaman calls weak and holds fixed the axis Rahaman calls dominant, so the width-only ablation cannot have tested the depth-driven spectral-bias mechanism it invoked Rahaman to motivate.**

**Fix — the second option is better.** (1) Minimal: drop the citation; the width objection stands on the verified NTK/NNGP lineage alone. (2) **Better: keep it and state the limit** — spectral bias is reported as primarily a *depth* phenomenon, the ablation sweeps width at fixed depth 2, and the depth-driven version of the objection **remains open**. One clause converts a miscitation into a correctly-scoped limitation, names a concrete follow-up, and pre-empts a reviewer who knows Rahaman.

**Consequence for the headline framing.** The paper is scrupulous that the width sweep "stops at 1024 while the kernel limits are asymptotic, so this answers the objection at practical widths and makes no asymptotic claim." That scrupulousness was not applied to depth. So **"seven controls, none survives" is a bare count doing rhetorical work at least one underlying control does not fully support**: capacity is eliminated *at fixed depth 2*, not eliminated. Stating each control's scope — width at fixed depth; σ at this ensemble construction — costs little and forecloses the line of attack.

### I. `ghasemipour2022pessimistic` — an over-extended analogy where the accurate version is more useful

**The claim (Confound 4):** the cross-model-class incomparability principle is owned by the interval-validity literature *"and **its offline-RL instance**."*

**Their entire scope is one surrogate class, Q-ensembles**, and their axis of comparison is an *internal training-procedure* choice — shared versus independent Bellman targets, full versus weight-shared ensembles. ### L. The conformal proposition is formally correct and practically inert — and the paper never says so

**This item was initially recorded as the audit's most serious finding, on a secondhand report that the proposition omits a load-bearing hypothesis. Reading the supplement directly showed the report was overstated, and the earlier framing is withdrawn** — propagating an overstatement is precisely the failure this audit exists to catch.

`supplement.tex:48` reads: *"Under a shifted proposal Π ≠ P **with density ratio w = dΠ/dP**, validity is restored by weighting the calibration quantile by w."* It defines w as **the true density ratio**, not an estimate. So the statement is exactly Tibshirani et al.'s weighted-conformal theorem and is **formally correct as written. The proposition is not missing a hypothesis and it is not wrong.**

**What is true, and still worth a fix.** The clause is correct and **inert in the paper's own setting**. Tibshirani et al.'s guarantee holds for *known* w; their abstract separates the estimated case and supports it **empirically only** — roughly 91.0% coverage against 90% nominal on airfoil data — with no theorem bounding the coverage gap under an estimated weight [55]. Angelopoulos & Bates corroborate: weighted procedures are *"exact when the magnitude of the distribution shift is known"* [56]. Here Π is the distribution of designs an optimizer proposes after ascending a surrogate — the setting where w is least knowable and arguably not well-defined, since the proposals are the output of a deterministic optimization concentrated on a low-dimensional set. Nothing in the paper estimates w or applies weighted conformal.

**Fix (one or two sentences), plus a free win.** Note after Proposition 2 that the clause requires a known or reliably estimable w, that none is available for optimizer-generated proposals, and that it is stated for completeness rather than applied. **Then take the win:** the supplement already reports that conformal repair *"restores in-distribution coverage to its 0.90 target on every task but leaves OOD coverage erratic"* — 0.00 on five tasks. That is *exactly what one should expect* when the precondition is unavailable. Saying so converts an unexplained table into a correctly-scoped negative result, and reinforces the paper's separate argument that premise coverage is separable from optimization outcome [57]. **Severity: moderate — a scoping omission around a correct proposition, ranked below the Demšar fabrication and the Fan inversion.**

**η² (eta-squared, the proportion of outcome variance attributable to a factor) is positively biased at *n* = 7, and the paper never says so.** Okada's Monte Carlo study, one million replications per condition, tabulates η² bias at **+0.054 at n=10 per group falling to +0.005 at n=100, always positive**, while ε² and ω² are always small and negative [61]; Liu states the bias firsthand and attributes the corrections to Kelley (1935) for ε² and Hays (1963) for ω² [62]. **Okada's simulation also overturns the folk belief that ω² is the least-biased correction — ε² is.** The paper's own bootstrap artifacts already contain the bias estimate, unreported: the bootstrap mean exceeds the point estimate in all four corners, by +0.0099 to +0.0184. **Fix: report ε² alongside η², and disclose the positive small-*n* bias with the artifact-derived estimate (see RANK 4).**

**The per-task normalizer is a fifth operating-point coordinate the paper never names.** The paper's central methodological claim is that any headline η² is a joint artifact of four coordinates — K, β, budget, engine corner — "so a headline that does not state all four is not reproducible." Every η² in the paper is computed on per-task min–max normalized cell means over nine cells, where the min and max are set by two of the nine arms *under comparison*. That endogenous form deviates from Design-Bench's own convention, which draws the range from a larger external dataset [89], and the critique is citable rather than hypothetical: Jordan et al. name this exact functional form as outlier-exploitable — *"algorithms could be near 0 or 1 if there is an outlier algorithm that does very well or poorly... We would like the evaluation procedure to be robust to the addition of poor algorithms"* [63] — and Bellemare et al., the *origin* of the technique, document it flipping a ranking [64].

Ranks are not a clean escape, since rank statistics are pool-dependent — and that property is owned by a primary the paper does not cite. Balduzzi et al. show that *"measuring performance by uniformly averaging over tasks in a benchmark suite is sensitive to the set of tasks that are included in the suite. Including redundant tasks, whether consciously or not, can easily skew average performance in favor of or against particular agents,"* with a worked case where duplicating one agent shifts another's Elo by 63 points at unchanged underlying skill [98]. Jordan's non-exploitability criterion descends from Balduzzi, so the paper's two normalizer authorities share one root; Benavoli, which the paper already cites elsewhere, is a separate and narrower point about post-hoc tests on mean ranks [43]. One further disclosure a robustness check surfaced: min-max-normalized residuals reject normality and homoscedasticity while rank-transformed residuals satisfy both, so the point estimate sits on an assumption-violating scale. The nonparametric bootstrap is the right hedge, but the scale is not disclosed. **Fix: name the per-task normalizer as a fifth operating-point coordinate wherever the four are enumerated, report the alternative-normalizer check, and cite Jordan [63], Bellemare [64] and Balduzzi [98] (see RANK 5).**

## (iii) Scope of Novelty, Ranked

### A. The boundary condition, first, because it governs everything below

Two positive findings sit unreported in the paper's own artifacts. Both are real. An earlier version of this audit paired them on the claim that **each survives exactly what the other fails**; that pairing is **FALSIFIED**, on two counts, and the corrected version is narrower.

First, the two are **not independent**. The interaction's normalizer-immune form *is* the raw-units contrast — the ensemble-versus-GP gap collapsing under perturbation and stretching under gradient and CMA — which is the same measurement as the 7/7 attenuation, on the same seven tasks. A pairing that leans on it twice is leaning on one dataset twice. Second, the interaction does **not** cleanly survive the floor-effect challenge: a floor effect under perturbation, compressing all three surrogate cells toward a common achievable value, would *generate* an interaction of exactly this shape, so the confound bears on the interaction's mechanistic reading as well. What survives both counts: **the asymmetry is visible in both normalized and raw units**, so it is not a normalizer artifact, and it is significant with intervals excluding zero in all four corners — while its **causal** reading remains unestablished for both halves at once, because the floor-effect confound is unresolved.

The substantive case rests on the four-corner intervals and the design-of-experiments argument.

Four reasons it is major rather than technical.

- **(1) It is the strongest available vindication of N6.** The entire case for a crossed factorial over one-factor-at-a-time is that OFAT cannot estimate interactions — a point the standard reference states in the paper's own notation: *"OFAT experimentation leaves us in the dark about factor interactions,"* and under an interaction the optimal setting of one factor *reverses* depending on the other's level [58]. Every near-miss in the ledger is structurally incapable of producing this number. **It is the answer to "why did anyone need to run this?"**
- **(2) It reframes the optimizer null, the paper's weakest passage.** The paper warns, correctly but without evidence, that a small η²_opt "licenses 'optimizer choice explains little variance' and never 'optimizer choice is arbitrary' — the second reading is false on our own data." **The interaction is that evidence and it is not cited there.** The supported statement: optimizer choice has a small *marginal* effect and a substantial *conditional* one, by 4–33×. **That pattern is textbook rather than anomalous**, which is the cheapest way to defend it: NIST/SEMATECH's worked full factorial reports a factor that *"plays a role in almost every significant interaction term, but is the least important main effect on its own,"* and warns that *"large interactions can obscure main effects"* [92] — structurally identical to η²_opt at 0.005–0.036 against η²_inter at 0.146–0.165.
- **(3) It is a positive, quantitative, significant result in a paper whose mechanism section is seven negatives.**
- **(4) It is invariant across the four operating-point coordinates the paper names** — but not across the fifth coordinate (i.M) identifies, since rank normalization roughly halves it and inverts its ordering against the optimizer in one corner.

**Precedent check, and it must be made in its defensible form.** The bare version — "no one in ML reports an interaction term" — is false, and a reviewer from the Freiburg lineage would kill it in one line: interaction reporting is *routine* inside the fANOVA tradition this paper's own design descends from. Hutter et al. 2014, cited here as a near-miss, carries twenty occurrences of `interaction` precisely because fANOVA decomposes into main effects **and** pairwise interactions by construction [3], and van Rijn & Hutter analyse each algorithm's configuration space in isolation — SVM, then random forest, then Adaboost, never jointly. Conceding that is what makes the residual sharp: interactions are reported all the time, **just never between "which surrogate model class" and "which search routine" as two independently manipulated pipeline components.** A widened sweep across ML benchmarking finds no instance of that. Schmidt et al.'s optimizer benchmark shows zero hits on all formal terms, offering only qualitative "performance highly depends on the problem" language [79]. Choi et al. argue rankings are confounded by asymmetric tuning budgets, which is not an interaction [80]. Steiner et al. explicitly cross augmentation strength × model size × data budget, call it *"interplay,"* and never compute a formal interaction statistic [81]. **Across three independent regions, no ML benchmark study reports and interprets an interaction between two independently manipulated pipeline components.** That is a strictly stronger framing than a bare novelty claim, because it concedes the routine case and isolates what is genuinely unowned.

**The positive design-of-experiments authority the paper lacks.** Its bibliography contains **zero** design-of-experiments citations, so its only warrant for the crossed design is Moosbauer's *negative* framing. Four open sources supply the positive mirror: the NIST/SEMATECH handbook on one-factor-at-a-time [58] and its worked full factorial [92]; the official SAS/JMP companion excerpt to Montgomery, which quotes the textbook's point that one-factor-at-a-time analysis cannot reveal whether a factor's effect depends on another factor [102]; and Box, arguing that interactions are practically decisive via an industrial case where "the life of a bearing can be increased fivefold if the two factors... are increased together," missed because "most engineers have, until recently, employed only one factor at a time experimentation" [59].

**The honest methodological counterweight cuts for the paper.** Sommet et al.'s preregistered metastudy of 159 psychology studies found median power to detect a typical interaction of just **.18**, with only 4% reporting an adequate shape-aware power analysis [60]: reported interactions are chronically underpowered precisely because typical interactions are small relative to their main effects. **This one is larger than an entire main effect.** McClelland & Judd's much-cited "less than 20% efficiency" figure is explicitly about *field* studies with restricted-range moderators, not designed experiments with manipulated, maximally separated levels — and this grid is the optimal-experimental-test case. Citing that literature correctly is a cheap display of exactly the methodological care the paper claims.

**Two qualifications must travel with it.** It is **synthetic-grid-specific**: on Design-Bench η²_inter is only 0.006–0.041 and subordinate to η²_opt there. Frozen surrogate cells are a *candidate* explanation — where a cell returns a bit-identical constant across all seeds, neither main effects nor interactions involving it can appear — but that is a hypothesis, not a resolution, and this audit over-stated it once already. Frozen cells are documented only on TF-Bind-8 and Ant, and Design-Bench's own η²_opt of 0.05–0.20 shows the axes are demonstrably not all flattened, which is what a general flattening account would predict. **The honest statement is that the interaction is a synthetic-grid result whose failure to generalise is currently unexplained**, and the scoping should rest on that rather than on an explanation. And it is an η², so it inherits the normalizer sensitivity of (i.M); promote it as an **existence-and-ordering claim** under a disclosed normalizer, with the rank exception stated, not as the stable quantity "0.15."

**RANK 6 — The landscape negative, and the one positive structural statement available. `FOLD-INTO-THIS-PAPER / CHEAP`. The UNEXPLORED finding — the paper does not attempt this analysis at all.**

Tested directly against `tab:sfull` under all three optimizers: **no standard landscape covariate predicts the GP-versus-ensemble gap.** Spearman correlation with dimension is 0.107 (*p* = 0.82) under gradient, −0.109 under perturbation, 0.071 under CMA — indistinguishable from zero under every optimizer. Textbook multimodality **actively mis-sorts**: within the four-function "many local minima" bucket the gap spans 2.09 to 2591.06, three orders of magnitude inside one category, while the only strictly unimodal task has the smallest gap of all. Separability fares no better, and the sharper form of the same negative is a span contrast: the three separable tasks' gaps run 2.09 to 21.20, roughly 10×, while the four non-separable ones run 0.19 to 2591, roughly 13,600× — the non-separable group contains both the extreme minimum *and* the extreme maximum, so the category does not sort the outcome at all. One reviewer rescue must be foreclosed before it is reached for: `code/mbo.py` applies an affine map from the shared [0,1]^d design space back to each function's exact native textbook domain (Branin to x₁ ∈ [−5,10], x₂ ∈ [0,15]; Styblinski to [−5,5]; Levy to [−10,10]; Rastrigin to [−5.12,5.12]; Griewank to [−600,600]), so the null is not an artifact of a flattening reparametrization. The tasks really do sit on their standard, well-characterized landscapes, which makes the non-result stronger rather than weaker. **This is a decisive negative from looking, not an absence of looking**, and two or three sentences close a hostile reviewer's "isn't this just landscape?" objection with a falsifiable, already-computed answer instead of the current one-line hedge.

The literature gap is real: the mature exploratory landscape analysis (ELA — characterizing a problem's landscape via computable features such as multimodality and separability) tradition has never been pointed at surrogate-class choice **in this exact offline, one-shot, GP-versus-ensemble framing**, operating instead at benchmark-suite scale to select *solvers* [67][68][69]. The stronger phrasing is deliberately not used: five sources were checked and two surveys return zero `surrogate` hits, but the lead to Yu et al. (2016) was blocked at IEEE Xplore and never read directly, so a specific niche precedent cannot be ruled out. The nearest structural cousin compares true against surrogate landscape features but switches surrogates online, per-iteration, inside a multi-objective evolutionary algorithm [70]. Malan's survey flags surrogate-landscape analysis as unresolved and reports the finding that makes it hard: features computed *through* a surrogate are "more indicative of the surrogate model than the original landscape" [71] — a circularity that bites when the object being selected is itself the instrument of measurement.

**Now the structural statement, which exists only in cross-section and which no single analysis produced.** The per-task gap ranking is **stable across optimizers at Spearman 0.84–0.96** — 0.84 gradient-versus-perturbation (*p* = 0.019), 0.96 gradient-versus-CMA (*p* < 0.001), 0.91 perturbation-versus-CMA (*p* = 0.005) — while the per-task gap *magnitude* collapses to ≈0.01 under perturbation against 0.735–0.762 under gradient and CMA. These look contradictory and are not: one measures relative ordering across tasks, the other absolute magnitude within an optimizer. **That combination rules out both a purely optimizer-side account, which would not preserve task ordering, and a purely task-side account, which would not collapse. Any surviving mechanism must be multiplicative — a task factor scaled by an optimizer-aggressiveness factor.** For a paper whose mechanism section is seven negatives and no positive causal test, that is worth more than an eighth negative. Weight it honestly: the 0.84–0.96 stability is descriptive at *n* = 7 while the collapse is bootstrapped, so the collapse is the better-evidenced half. One documented curiosity is worth a clause: Griewank is known to get *simpler* to optimize with increasing dimension despite more local minima, so attributing the ensemble's collapse there to ruggedness is probably backwards.

**RANK 7 — Report the equivalence bound the paper already computed. `FOLD-INTO-THIS-PAPER / CHEAP`.** The released `stats.py` already computed a paired two-one-sided-tests (TOST) bound — the standard procedure for testing whether a difference is small enough to be practically negligible: gap **0.3762**, 90% CI [−0.1078, 0.8602], effect bound **0.4840**, **not equivalent at either a 0.5 or a 0.3 margin.** The supplement's entire treatment is one clause saying such tests "are computed." The paper is scrupulous about never claiming equivalence and correctly says a failure to reject is not a demonstration of absence [42] — **and it has the actual test in hand, and it is informative:** a positive statement about what the null does and does not license, stronger than the disclaimer in its place. Report the bound and verdict, cite Lakens [82], who is absent from the bibliography, and carry his caution that rejecting small effects requires large samples. A confirmed negative closes the thread: there is no ML-benchmark-specific equivalence-testing literature.

**RANK 8 — Give the inversion result its name, and advertise the replication the paper obscures. `FOLD-INTO-THIS-PAPER / CHEAP`. The clearest under-explained finding.** The paper states its inversion flatly: "a demonstration within this grid, descriptive at *n* = 7 tasks, not a mechanism." **It is an instance of a named, decade-old failure category.** Offline RL formalizes it as **safe policy improvement** — P(ρ(π,M) ≥ ρ(π_b,M) − ζ) ≥ 1 − δ, the requirement that a policy learned offline not be worse than the baseline it was given, with high probability [75]; SPIBB (safe policy improvement with baseline bootstrapping) proves a ζ-approximate guarantee and measures safety via 1%-CVaR (conditional value at risk — the mean of the worst-case tail) across roughly 100,000 randomly generated Markov decision processes, precisely because algorithms lacking such a guarantee return sub-baseline policies in a nontrivial fraction of runs [74]. The gap-expanding theorem of CQL (conservative Q-learning) supplies a second reusable frame: the learned value function *widens*, never narrows or inverts, the in-distribution-versus-OOD gap relative to the truth [76]. **The reframing: the inversion is not an awkward number, it is the observation that offline MBO optimizers ship with no safe-improvement guarantee, and the absence bites.** Two sentences, two citations.

Separately and freely: 0.406 and 0.405 are not one measurement at two precisions. They are **two independent runs at the same operating point** — the β-sweep endpoint at β=2 (10 seeds) gives 0.40636; the headline corner (30 seeds) gives 0.40455 — landing 0.0018 apart. **A paper whose central scalar is challenged as an operating-point artifact should be advertising an independent reproduction of it**, not letting a reader assume rounding.

**RANK 8a — Give the frozen cells their name as well. `FOLD-INTO-THIS-PAPER / CHEAP`. The second under-explained finding.** The paper reports bit-identical returns across sixteen seeds in two GP classes as an anomaly of the Design-Bench arm. It is the offline, confidence-bound instance of a formalized inconsistency result: Yarotsky's Theorem 3 proves that expected-improvement-driven Bayesian optimization started at the true optimum has a trajectory converging back to that single point and *"not dense"* [24]. Two adjacent formalizations bracket it and must be named as *different* rather than folded in — Ament et al. [87] and Kim & Choi [25], distinguished at (i.B). **Framed this way the frozen cells stop being an embarrassment in a results table and become the empirical, offline counterpart of a known theoretical failure mode** — and the paper's evidence is the stronger half, since sixteen bit-identical seeds across two GP implementations on a continuous task with no argmax decode is not in Yarotsky. Two sentences, three citations.

### C. Forward implications

The finding with the longest half-life is neither the headline η² nor the seven eliminations. It is the **conditionality** — that the surrogate-class advantage is largely a property of the surrogate-optimizer *pair* rather than of the surrogate. If that holds beyond this grid, it dissolves the framing question the subfield has been arguing about. The dispute between the surrogate-side lineage and the optimizer-side lineage [52] is not a dispute about which factor matters; it is a dispute about which conditional slice each camp is standing in. A surrogate paper evaluated under gradient ascent and an optimizer paper evaluated on one fixed surrogate are estimating different quantities, and neither is estimating the thing the field reports.

That has immediate consequences for how the next generation is evaluated. The 2026 frontier is generative — diffusion language models [6][15], support-proximity diffusion estimation [14], flow-based domain models [16], meta-learned surrogates [18], ranking-theoretic surrogates [17], conformal per-candidate certification [19]. Almost all bundle the generative model and the search procedure into a single reported number, exactly as the lineage this paper dissects does, and several bundle them *inseparably*: a diffusion policy trained end-to-end through data-augmentation, supervised fine-tuning and reinforcement-learning stages has no clean optimizer factor to vary at all. **If a crossed factorial is going to remain runnable in this subfield, it has to be run now, on the last generation of methods where the two axes are still separable.** That is a timeliness argument the paper does not make and could make in one sentence.

The successors are visible from here; RANK 9 lists them. The natural sibling to the existing stability benchmark for offline optimizers [20] — a benchmark for *attribution* rather than performance, with the surrogate and optimizer axes shipped separable by construction — does not exist, and this paper's grid is the closest thing to a prototype. Each is a paper. The submission under audit is the instrument that makes them askable.
